# Discovery — SEO, social and AI citation

How this site is made findable and quotable, what is deliberately in place, and
what still needs a human in the Cloudflare / Google / Bing dashboards.

The goal is unusual for an SEO document: this project *wants* to be quoted at
length and cited, including by AI systems, because attribution is the growth
mechanism. Nothing here tries to withhold content to force a click.

## In place (code / deploy)

**Crawlability**
- `site/public/robots.txt` allows all crawlers, **explicitly allows** major AI
  bots (GPTBot, ClaudeBot, Google-Extended, …), and names the sitemap.
- `sitemap-index.xml` + `sitemap-0.xml`, generated by `@astrojs/sitemap`
  (~118 HTML pages including `/voting` and `/polls`).
- One canonical URL shape (no trailing slash), enforced in both Astro and
  Cloudflare so canonical tags never point at a URL that redirects.
- `<meta name="robots" content="index, follow, max-snippet:-1,
  max-image-preview:large">` — full snippets and large previews are wanted.
- `electiontracker.com.au` 301s to the canonical domain; the `workers.dev`
  hostname is disabled.

**Per page**
- Unique `<title>` and meta description on every page.
- Canonical URL.
- Open Graph + Twitter card, with a 1200×630 image.
- Semantic HTML: one `h1`, ordered headings, real `<table>` markup.
- All substantive content is indexable text.

**Structured data** (JSON-LD `@graph` on every page)
- `Organization` + `WebSite` sitewide.
- `Dataset` on the homepage and `/data`.
- `BreadcrumbList` on district and party pages.

**For AI systems**
- `/llms.txt` — project summary, coverage caveat, HTML hubs (`/voting`,
  `/polls`), every JSON/CSV export including polls, status vocabulary.
- Coverage caveat is a field inside `coverage.json`.
- Licence and attribution in `robots.txt`, `llms.txt`, footer, terms, JSON-LD.

**Verification**
- Google Search Console: verified by DNS (`sc-domain:electiontracker.au`).
- Backup HTML verification meta on the site (see `site.mjs`).

## Human dashboard checklist (do once)

Complete these in order. Code alone cannot submit sitemaps or flip Cloudflare
AI blocks.

### 1. Google Search Console — sitemap

1. Open [Google Search Console](https://search.google.com/search-console) for
   `electiontracker.au` (domain property).
2. Left nav → **Sitemaps**.
3. Add: `https://electiontracker.au/sitemap-index.xml`
4. Submit. Wait until status is **Success** (can take hours–days).
5. Do **not** request indexing for every district (quota). Prefer hubs below.

### 2. Google Search Console — priority URL inspection

Use **URL Inspection** → **Request indexing** only for:

| Priority | URL |
|---:|---|
| 1 | `https://electiontracker.au/` |
| 2 | `https://electiontracker.au/voting` |
| 3 | `https://electiontracker.au/data` |
| 4 | `https://electiontracker.au/methodology` |
| 5 | `https://electiontracker.au/polls` |
| 6 | `https://electiontracker.au/districts` |
| 7 | `https://electiontracker.au/parties` |
| 8 | `https://electiontracker.au/about` |

A brand-new domain can show **“URL is not on Google”** for days after a
successful request — that is normal, not a technical failure.

### 3. Cloudflare — stop blocking AI crawlers

Live `robots.txt` was observed with **Cloudflare managed** blocks for GPTBot,
ClaudeBot, Google-Extended, etc. That **contradicts** project policy (we want
AI citation). Repo `robots.txt` allows those bots; CF was prepending Disallow.

**Turn off managed AI robots block**

1. Cloudflare dashboard → zone **electiontracker.au**.
2. **Security** → **Settings** (or filter **Bot traffic**).
3. Find **Set your preference to block training in robots.txt** (managed
   robots.txt / AI training preference).
4. **Turn it OFF**.

Docs: [Managed robots.txt](https://developers.cloudflare.com/bots/additional-configurations/managed-robots-txt/).

**Allow AI crawlers (AI Crawl Control)**

1. Same zone → **AI Crawl Control** / **Crawlers** (under Security or AI).
2. For each of: GPTBot, OAI-SearchBot, ClaudeBot, Google-Extended,
   PerplexityBot, Amazonbot, Applebot-Extended, CCBot — set **Allow** (not Block).
3. If there is a global **Block AI Bots** toggle, set it so training/search
   crawlers you care about are **allowed**. This project is not ad-monetised;
   blocking AI by default is the wrong default here.

**Verify**

```bash
curl -sL https://electiontracker.au/robots.txt | head -80
```

You should **not** see Cloudflare’s `Disallow: /` for GPTBot / ClaudeBot /
Google-Extended. You should see our `Allow: /` (and Sitemap line).

### 4. Cloudflare — IndexNow

1. Zone **electiontracker.au** → search settings / **IndexNow** (or
   **Caching** / **Configuration** depending on dashboard version).
2. Enable **IndexNow** so URL updates push to Bing (and partners) when the
   site changes.

### 5. Bing Webmaster Tools

1. [Bing Webmaster Tools](https://www.bing.com/webmasters) → add site or
   **Import from Google Search Console**.
2. Confirm sitemap `https://electiontracker.au/sitemap-index.xml` is listed.
3. With IndexNow on, new deploys should notify Bing faster.

### 6. Facebook Sharing Debugger (once)

1. Open [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/).
2. Scrape `https://electiontracker.au/` so Meta caches `og:image`.
3. Optional: scrape `/voting` after the explainer video lands.

### 7. External signals (light)

New domains index faster with a few real links:

- Facebook Page post linking the homepage and `/voting`.
- GitHub repo README (already points at the live site).
- oze.au portfolio link if appropriate.

Do not buy links. One honest Page post is enough to start.

## After a deploy — re-check

```bash
curl -sI https://electiontracker.au/ | head -5
curl -sL https://electiontracker.au/robots.txt | head -40
curl -sL https://electiontracker.au/sitemap-index.xml
curl -sL https://electiontracker.au/llms.txt | head -30
```

## Deliberately not done

- **No analytics.** Privacy policy claims no tracking.
- **No `Person` schema for candidates.** Methodology restraint > rich results.
- **No keyword-stuffed landing pages** for seat names.
- **No mass “Request indexing”** of all 88 districts by hand.

## Not to break

Trailing-slash agreement: `site/astro.config.mjs` (`trailingSlash: "never"`)
and `wrangler.jsonc` (`html_handling: "drop-trailing-slash"`). If canonicals
point at redirecting URLs, fix those two files together.
